# OpenMake Companion 설치 안내 (macOS · Windows)

Companion 은 서명 없이 배포합니다. 그래서 처음 설치·실행할 때 OS 가 보안 경고를 띄웁니다. 아래 순서로 해제하세요.
회사가 배포한 파일인지 확인하려면 관리자가 알려 준 주소(OpenMake 웹의 다운로드)에서 받은 파일만 실행하세요.

## Windows

1. 관리자가 안내한 주소에서 `OpenMake-Companion-Setup-<버전>.exe` 를 내려받습니다.
2. 파일을 실행하면 "Windows 의 PC 보호" 화면이 나옵니다. **추가 정보**를 누른 뒤 **실행**을 누릅니다.
3. 설치가 끝나면 작업 표시줄 오른쪽(알림 영역)에 Companion 아이콘이 생깁니다. 보이지 않으면 `^` 를 눌러 숨겨진 아이콘을 확인합니다.
4. 아이콘을 오른쪽 클릭 → **설정** 에서 서버 주소와 API key 를 넣고 저장합니다. API key 는 OpenMake 웹의 **API 액세스** 화면에서 `bridge` 스코프로 발급합니다.
5. 아이콘을 오른쪽 클릭 → **작업 폴더 연결** 로 에이전트가 쓸 폴더를 고릅니다.

- 에이전트가 명령을 실행하려 할 때마다 확인 창이 뜹니다. Windows 에서는 "이 작업 동안 모두 허용"이 없고 명령마다 확인합니다.
- 브라우저를 쓰게 하려면 설정에서 **에이전트의 브라우저 사용 허용**을 켭니다. 평소 쓰는 Chrome 이 아닌 전용 창이 열립니다.
- 사내 보안 프로그램이 설치나 실행을 막으면 관리자에게 알려 주세요.

## macOS

1. `OpenMake-Companion-<버전>-arm64.dmg` 를 열고 앱을 **응용 프로그램** 폴더로 옮깁니다.
2. 처음 실행하면 "확인되지 않은 개발자" 경고가 나옵니다. **시스템 설정 → 개인정보 보호 및 보안** 으로 가서 아래쪽의 **그래도 열기**를 누릅니다.
3. 메뉴 막대의 Companion 아이콘 → **설정** 에서 API key 를 넣고, **작업 폴더 연결**로 폴더를 고릅니다.

## 업데이트

- Windows: 앱이 시작할 때 새 버전을 확인하고, 있으면 내려받을지 묻습니다. 받은 파일이 게시된 것과 같은지 확인한 뒤 설치 프로그램을 실행합니다(이때도 2번의 경고가 다시 나올 수 있습니다). 트레이 메뉴의 **업데이트 확인**으로 직접 확인할 수도 있습니다.
- macOS: 메뉴의 **업데이트 확인**.

## 연결 해제와 제거

- 트레이(메뉴 막대) 아이콘 → 폴더 → **연결 해제**. 분실·퇴사 시에는 관리자가 API key 를 폐기하면 그 PC 의 연결이 끊깁니다.
- Windows: **설정 → 앱 → 설치된 앱** 에서 OpenMake Companion 을 제거합니다.

> 이 안내의 Windows 절차는 실제 설치 파일로 따라 해 보지 않고 작성했습니다. 첫 설치 파일이 나오면 화면과 맞는지 확인해 고칩니다.
